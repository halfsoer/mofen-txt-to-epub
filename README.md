# 墨分 mofen-txt-to-epub

Mac 上双击将文件夹里的 `.txt` 批量转换成 `.epub`。

支持中文章回识别（第X章、番外、序章、完结感言等）、英文 Chapter、弱编号、封面自动生成。

## 使用方法

1. 把 `开始转换.command` 放到小说 txt 所在的文件夹（或它的上层文件夹）
2. 双击运行
3. 转换完成后，同名 `.epub` 会生成在 txt 旁边，**原 txt 会被删除**

## 修改说明

原版有 40MB 文件大小上限，本仓库版本已移除该限制，任意大小的 txt 都会尝试转换。

## 注意事项

- 仅支持 macOS（依赖 `osascript` + JavaScript）
- 转换成功后会删除原 txt，请先备份
- 章节识别基于正则，复杂格式可能需要手动调整
